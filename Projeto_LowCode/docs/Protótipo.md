# **Breve explicação de funcionamento**: 
O Project Scraper é um agregador de vagas de emprego. O sistema consome a API pública da Remotive,
filtra as vagas por critérios de localização para garantir que apenas oportunidades acessíveis a candidatos brasileiros sejam exibidas
